A capstone-style collection of machine-learning cybersecurity materials focused on adversarial attacks, adversarial training, federated learning, and hands-on lab exploration.

## Project Story

Machine learning systems can fail in ways that traditional software systems do not. This project explores those risks through presentations, reports, and lab packages that introduce ML security concepts from both an attacker and defender perspective.

## Topics Covered

- Adversarial machine learning
- Attack types against ML models
- Defensive adversarial training
- Federated learning concepts
- ML cybersecurity risk analysis
- Lab-based learning for security workflows

## Suggested Learning Path

1. Start with the Week 1 and Week 2 capstone decks.
2. Review the adversarial attack presentation to understand threat models.
3. Study adversarial training as a defense strategy.
4. Explore federated learning for privacy-aware model training.
5. Open the lab zip files and run the included exercises in a controlled environment.
6. Read the final analysis report to connect the technical work into a complete security narrative.

## Why This Matters

As ML models move into production systems, attackers can target model inputs, training data, inference behavior, or distributed learning workflows. Understanding those risks helps build models that are more reliable, more explainable, and harder to manipulate.
